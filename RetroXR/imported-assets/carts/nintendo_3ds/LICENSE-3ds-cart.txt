Nintendo 3DS Game Card (3ds_cart.glb)

Own work. Modelled in Blender from Ryan McClelland's photographs and caliper
measurements of a 3DS Game Card (33 mm body + 2 mm tab = 35 x 35 x 3.8 mm) and
reduced for real-time use (the mobile close export, 13,329 triangles); the
source .blend, build scripts and references live outside this repository
(codex-photos/nintendo/ds/cart). Unmapped shell triangles were given UVs with
Tools/glb/fix_unmapped_uvs.py (--tile 34). The CartridgeLabel mesh carries a
plain white placeholder that the cartridge script replaces with the scraped
label art.

Licensed with the rest of RetroXR (see the repository LICENSE).

No third-party marks are carried: the moulded Nintendo logo and the
"CTR-005 PAT.PEND." line on the back are left off. The printed lot code on the
back (AJREZ40342, from the photographed card) and the board's silkscreen
(DS D-10 D01-10) remain.
