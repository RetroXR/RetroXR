NES Game Pak shell (nes_cart.glb)

Own work. Ryan McClelland's photographs and measurements of a US NES Game Pak (a
gray three-screw shell, Maniac Mansion), rebuilt as a parametric Blender model
registered to those photographs and reduced for real-time use (the optimized LOD0:
2,766 triangles, 120 x 134 x 17 mm). The source .blend files, build scripts and
references live outside this repository (codex-photos/nintendo/nes/cart:
scripts/build_cartridge.py, scripts/export_retroxr.py).

The shell's stipple is a tangent normal map with a roughness map of its own
(generated noise). The Label mesh carries a plain white placeholder that the
cartridge script replaces with the scraped label art. The rear caution sticker is
redrawn artwork, set in Arimo (Copyright 2020 The Arimo Project Authors, SIL Open
Font License 1.1); the raised PAT.PEND. MADE IN JAPAN lettering on the rear plaque
is baked into the NES_Plaque_Baked normal map. No font file is included.
